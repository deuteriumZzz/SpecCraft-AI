# Термометр цифровой ТЦ-200

Цифровой измерительный прибор термометр цифровой ТЦ-200 представляет собой устройство, предназначенное для измерения температуры воздуха и жидкостей в процессе работы. Прибор охватывает рабочий диапазон измерений от -50 до +300 градусов Цельсия. Для автономной работы изделия используется питание от встроенной батареи. Данная модель применяется для контроля параметров среды в различных условиях согласно заложенным характеристикам. Устройство обеспечивает фиксацию температурных показателей в указанном диапазоне температур без применения дополнительных элементов питания извне. Эксплуатация термометра связана с измерением температуры воздуха и измерением температуры жидких сред. Все параметры прибора строго соответствуют заявленным техническим характеристикам. Конструкция устройства оптимизирована для выполнения поставленных измерительных задач на объектах различного назначения. Изделие поставляется готовым к эксплуатации с учетом встроенного источника питания.

## Характеристики

| Параметр | Значение |
| --- | --- |
| диапазон измерений | -50…+300 °C |
| питание (из описания) | от встроенной батареи |
| класс точности | данных нет |
| тип корпуса | данных нет |
